<h2>🚀 What Is Weekend Getaway?</h2>
<p>Weekend Getaway is a smart trip planner that combines the power of large language models (AI) with live web search. It helps you discover the best weekend destinations, then builds complete, fact-checked itineraries including trains, hotels, and food recommendations. No coding required.</p>

<h2>🤖 Powered By</h2>
<ul>
  <li>AI (GLM-4, OpenAI API) for intelligent suggestions</li>
  <li>Live web search for real-time data</li>
  <li>Python & Streamlit for a smooth user interface</li>
  <li>Pydantic for data accuracy</li>
  <li>WeasyPrint to generate printable itineraries</li>
</ul>

<h2>🖥️ How to Use</h2>
<ol>
  <li>Open the Weekend Getaway app after installation.</li>
  <li>Enter your departure city and preferred weekend dates.</li>
  <li>Click "Plan My Getaway" – the AI will search the web and suggest top-ranked destinations.</li>
  <li>Review itineraries for trains, hotels, and food.</li>
  <li>Export your plan as a PDF or view it on screen.</li>
</ol>
